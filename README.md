# CodeAlpha_StockPortfolioTracker

Simple stock portfolio tracker in Python (CodeAlpha Python Programming Internship – Task 2).

## Features
- User enters stock symbols and quantities
- Prices come from a hardcoded dictionary (AAPL, TSLA, GOOGL, MSFT, AMZN)
- Shows each holding and total investment value
- Optionally saves the result to `portfolio_result.txt`

## Concepts used
`dictionary`, `input/output`, `basic arithmetic`, `file handling`, `functions`

## Run
```
python stock_tracker.py
```
